# Kicktipp World Cup 2026

## Code to retrieve the admiral.at odds for all the World Cup games

This notebook serves as a precursor for scraping the matchday data during the FIFA World Cup 2026.

To get started, follow these three steps.

1. Create a `kicktipp.de` account and join a World Cup prediction tipround

2. Create the `login.txt` file in your directory with your credentials:

```
USERNAME: your-kicktipp-username
PASSWORD: your-kicktipp-password
TIPROUND: your-kicktipp-tipround
```

3. Run the `introduction.ipynb` notebook to retrieve the odds from `admiral.at` and translate them into the argmax tip for each of the Bundesliga games

As soon as the World Cup prediciton games come online, we will update this repo accordingly.
